# JingYi Town Website | 静怡镇官网

## 2026-09-22
五洲大陆服务器与云霄服务器合并为凌霄服务器组，官方网站的搭建任务交由其余人员负责，本网站改为一个小镇的博客
### 静怡镇是什么？
静怡镇是五洲铁道服务器（WRMS）下的一个小镇子，由我和一众玩家共同搭建。
取名“静怡”，原先想的是两服在M奥时期经历过如此高压的工作氛围，所有参与过M奥建设的玩家需要一个地方去放松自己，故取名“静怡”。
静怡镇的组成为静怡岛全岛及其附属岛屿。目前有一个静怡站，当然还有个委托建造的西静怡站（tmd要不是没人造早就开始整这个镇子的其他建筑了）。
### 为啥要搭建一个小镇的网站？
首先刚才已经强调，服务器官方网站不由我负责搭建，而是由其余人员负责搭建。
其次我认为静怡镇应该有一个属于自己的故事，而不只是服务器的一个小镇。
再其次我近期已经开始学习了前端开发，想搭建一个自己的博客，所以就决定搭建一个小镇的网站。
### 这个网站有什么用？
1.介绍目前镇子的一些建筑
2.介绍镇子上存在的玩法
3.给这个镇子写个故事

总之，慢慢来吧。
